Fine print for Adelaide

Before you build on it

  • Web Functions: Node.js only.
  • Regions: N. Virginia, Ohio, Oregon, Tokyo, Ireland. Not Sydney.
  • Memory is still billed while waiting.
  • MicroVMs: suspended time counts toward the 8-hour limit; snapshots are billed.
  • Managed Instances: the 90-minute timeout doesn’t apply to synchronous calls.
  • Check data residency before sending agent work offshore.
